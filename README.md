# 🎨 CSS Animation Examples

A simple HTML and CSS project demonstrating different types of **CSS animations** using shapes and elements.

## ✨ Features

This project includes several CSS animation examples:

* 🔴 **Color Animation** — Changes the box color over time.
* ↕️ **Move Animation** — Moves the box vertically.
* 🔄 **Rotate Animation** — Rotates the box through 360 degrees.
* 📈 **Pulse Animation** — Increases and decreases the size of the box.
* 👻 **Fade Animation** — Changes the opacity of the box.
* ⏳ **Loading Animation** — Creates a rotating loading circle.
* ⬜ **Square Path Animation** — Moves a box around a square path.
* 🔵 **Google Animation** — Creates a bouncing animation using multiple colored circles.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS `@keyframes`
* CSS `transform`
* CSS `animation`
* Flexbox

## 🎬 Animations Included

### 1. Color

The box smoothly changes between different colors using CSS keyframes.

### 2. Move

The box moves up and down using the `translate()` transform.

### 3. Rotate

The box continuously rotates from `0deg` to `360deg`.

### 4. Pulse

The box grows to `1.5x` its original size and then returns to its normal size.

### 5. Fade

The box changes its opacity from fully visible to partially transparent and back.

### 6. Loading

A circular element continuously rotates to create a loading effect.

### 7. Square Path

A box moves around the four corners of a square container.

### 8. Google Animation

Five colored circles use animation delays to create a sequential bouncing effect.
